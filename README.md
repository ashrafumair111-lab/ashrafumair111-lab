🧠 AI & LLM Engineering

My current focus is moving beyond traditional application development into AI-powered software systems.

🔍 Retrieval-Augmented Generation (RAG)

I'm particularly interested in building production-grade RAG systems that allow LLM applications to work with external knowledge using vector search and semantic retrieval.

RAG Pipeline:

Documents
    ↓
Document Loading
    ↓
Text Splitting / Chunking
    ↓
Embeddings (OpenAI, HuggingFace, Ollama)
    ↓
Vector Database (Qdrant, Chroma, FAISS)
    ↓
Similarity Search / Retrieval
    ↓
Relevant Context
    ↓
LLM
    ↓
Generated Answer

Areas I'm exploring:

- 📄 Document loading and processing (PDF, DOCX, TXT, Markdown)
- ✂️ Text chunking strategies (Recursive, Semantic, Agentic)
- 🔢 Embeddings and embedding models

- 🔎 Semantic search and similarity scoring
- 🎯 Advanced retrieval strategies (MMR, Hybrid Search, Re-ranking)
- 🧠 Context-aware generation and prompt engineering
- 🔗 End-to-end RAG pipelines with LangChain

🔗 LangChain & LangGraph

I'm especially interested in the combination of LangChain and LangGraph for building production-oriented LLM applications.

LangChain

Used for building components and pipelines around LLM applications such as:

LLM
 ↓
Prompt
 ↓
Retriever (Vector DB — Qdrant, Chroma)
 ↓
Tools
 ↓
Structured Output
 ↓
Application

LangGraph

Used for designing more complex, stateful agent workflows:

          ┌──────────────┐
          │     START    │
          └──────┬───────┘
                 ↓
          ┌──────────────┐
          │     Agent    │
          └──────┬───────┘
                 ↓
        ┌────────┴────────┐
        ↓                 ↓
     Tool Call        Final Answer
        ↓
     Observation
        ↓
      Agent
        │
        └──────→ Continue / Finish
