## 👨‍💻 About Me

I'm a Software Developer and aspiring AI Engineer focused on building reliable backend systems, scalable full-stack applications, and real-time AI-powered software.

My journey started with programming fundamentals and moved into full-stack development with React, Node.js, Express, MongoDB, and MySQL. I'm now expanding into AI Engineering, Voice Agents, RAG systems, and scalable backend architecture.

I'm particularly interested in how production systems handle increasing traffic, reduce response times, process background jobs, and maintain reliability.

- 🎙️ **Voice AI:** LiveKit, Deepgram, Tavus, WebRTC, STT and TTS
- 🤖 **AI Engineering:** LLMs, RAG, AI Agents, LangChain, LangGraph
- 🔎 **Vector Search:** Qdrant, Chroma, FAISS, semantic search

## 🚀 What I Do

### 🎙️ Real-Time Voice AI & Agents

I explore real-time conversational AI systems that combine speech recognition, LLM reasoning, and speech generation.

- **LiveKit:** Real-time audio/video communication and WebRTC infrastructure
- **Deepgram:** Speech-to-text and voice processing
- **LLM Integration:** Context-aware responses and tool calling
- **Tavus:** Interactive AI avatar and video experiences
- **TTS:** Text-to-speech integration for conversational agents

### 🤖 RAG & LLM Engineering

I build knowledge-based AI applications that connect LLMs with external documents and information.

- Document loading, chunking, and metadata handling
- Embeddings and vector similarity search
- Qdrant, Chroma, and FAISS
- Hybrid search and reranking
- Retrieval-Augmented Generation (RAG)
- LangChain and LangGraph workflows
- AI agents, tool calling, and multi-step execution

### ⚙️ System Design & Backend Scalability

I study and implement backend patterns that help applications remain responsive and reliable as traffic increases.

- **Redis:** Caching, cache-aside patterns, TTL, and session storage
- **Nginx:** Reverse proxy, load balancing, and traffic distribution
- **BullMQ:** Asynchronous background jobs, retries, and job queues
- **Horizontal Scaling:** Running multiple application instances
- **Vertical Scaling:** Increasing CPU, RAM, and other server resources
- **Database Optimization:** Indexing, efficient queries, and connection management
- **Reliability:** Stateless services, fault tolerance, and high availability
- **Docker:** Containerization and consistent deployment environments

### 🌐 Backend & Full-Stack Development

I work across the application lifecycle, from designing REST APIs and database schemas to developing frontend interfaces and deploying applications.

- React frontend development
- Node.js and Express.js backend APIs
- MongoDB and MySQL integration
- Authentication and authorization
- Git, GitHub, and collaborative development
- Docker-based deployment and CI/CD
